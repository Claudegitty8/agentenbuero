# Agentenbüro

Ein Lernspiel für Erwachsene, die Claude schon nutzen, aber keine Informatiker sind. In einer kleinen Geheimzentrale schickst du den Einsatzroboter «Echo» auf Alltagsaufträge. Echo führt jeden Funkspruch genau so aus, wie er ankommt. Fehlt etwas, passiert genau der Fehler, den echte KI machen würde.

Du lernst: gute Aufträge (Prompts), Projekte und Gedächtnis, Skills, Konnektoren, Agenten, Subagenten, Hooks und Plugins. Was du baust, kopierst du mit «In Claude ausprobieren» in dein echtes Claude.

- Läuft im Browser, fürs Handy gemacht, ohne Konto.
- Dein Spielstand bleibt auf deinem Gerät. Keine Cookies, kein Tracking.
- Stand: Version 0.1, Kapitel 1 spielbar.

**Inoffiziell:** Das Agentenbüro ist kein Angebot von Anthropic und nicht mit Anthropic verbunden. Claude und Claude Code sind Marken von Anthropic.

## Für Entwickler

- `npm run pruefen`: alle Tests und die Inhaltsprüfung.
- `npm start`: lokal unter http://localhost:8080.
- Regeln für die Arbeit am Spiel: `CLAUDE.md`. Stand: `docs/STAND.md`.
- Die Technik stammt aus dem Lernspiel «KI-Studio» desselben Besitzers.
